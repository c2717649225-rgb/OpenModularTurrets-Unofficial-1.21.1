## 概述

该模组是对 [开放式炮台 (Open Modular Turrets)](https://www.mcmod.cn/class/539.html) 的 **1.12.2 向 1.21.1 社区移植版**。（原作目前已经在 1.20.1 重生）

100% 还原原版经典玩法，基于现代 **Minecraft 1.21.1 + NeoForge 21.1.x** 平台重构，具备更优异的性能与 Dedicated Server 专用服务端稳定性。

---

## 模组特色

### 1. 模块化基座设计
- 提供 **Tier 1 至 Tier 5** 五个等级的模块化基座；
- 随着基座等级提升，能承载更高阶的炮塔和解锁更多附加组件与升级。

### 2. 10 种特色防御炮塔
- **低级投射炮塔 (Disposable)**：早期低成本基础防守。
- **机关枪炮塔 (Machine Gun)**：极高射速，压制常规怪物。
- **榴弹炮塔 (Grenade) & 火箭炮塔 (Rocket)**：范围高爆 AOE 伤害，摧毁成群敌人。
- **激光炮塔 (Laser)**：高能光束连续输出，高精准打击。
- **磁轨炮塔 (RailGun)**：高伤害穿透打击，无视护甲。
- **土豆加农炮塔 (Potato Cannon)**：趣味农业防守，使用土豆/胡萝卜作弹药。
- **燃烧弹炮塔 (Incendiary)**：附带烈焰燃烧效果。
- **相位力场炮塔 (Relativistic)**：减速并控制范围内敌对目标。
- **传送炮塔 (Teleporter)**：强制将入侵者随机传送开。

### 3. 丰富的附加组件与升级
- **太阳能面板 (Solar Panel)**：昼间自发电，无忧续航。
- **红石反应堆 (Redstone Reactor)**：消耗红石粉/红石块提供高额能量。
- **伤害放大器 (Damage Amp)**：百分比提升炮塔基础伤害。
- **基座伪装 (Camouflage)**：可将基座伪装成任何普通方块，完美融入建筑外观。
- **能力升级**：射程加倍、精度提升、射速加快、能效节省与散弹 (ScatterShot) 模式。

> 以上所有内容均为移植前的原模组经典内容。
