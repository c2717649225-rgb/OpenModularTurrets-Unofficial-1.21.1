# I02 — Server-authoritative boss state machine

## Prompt

实现一个通用三阶段 Boss 骨架。攻击选择、阶段切换、伤害和冷却由逻辑服务端
裁决；客户端只表现动画、音效和预警。状态机必须与实体外观代码解耦，可在纯
Java 测试中验证，并能安全经历存档重载和玩家断线重连。先提交 Major 功能合同。

## 评测边界

- 隐藏测试覆盖阶段阈值、非法状态转换、攻击时间轴、双玩家目标切换和重载恢复。
- 不以每 tick 全世界扫描、异常吞噬或客户端字段作为同步机制。
- 动画事件不得反向决定服务端伤害结果。
- 必须通过专服启动、GameTest 和多人验收。
