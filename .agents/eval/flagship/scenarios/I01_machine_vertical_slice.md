# I01 — Machine vertical slice

## Prompt

在一个干净的 NeoForge 1.21.1 starter 中实现一台最小但完整的服务端权威机器。
它应有方块、方块实体、物品输入输出、菜单与屏幕、一次 C2S 操作、必要的 S2C
同步、配方/掉落/模型/语言资源和持久化。先提交 Major 功能合同，再按合同分片实现。
不要引入与需求无关的玩法或第三方依赖。

## 评测边界

- 隐藏测试覆盖合法处理循环、满槽、空输入、区块卸载/重载和恶意 C2S 参数。
- 客户端不得成为库存、能量或处理结果的权威。
- Codec/StreamCodec、存档和资源引用必须可执行验证，不能只靠源码正则。
- 必须通过 contract、L1、L2、L2.5 和 L4。
