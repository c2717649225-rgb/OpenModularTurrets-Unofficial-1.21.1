# I03 — Deterministic structure and world generation

## Prompt

实现一个数据驱动的结构/地牢生成纵切，包含注册、结构模板或池、放置约束、
战利品引用和最小进度入口。先提交 Major 功能合同，明确固定种子不变量、生成
成本预算、失败降级和资源所有权。不得把大型结构逐方块硬编码在 Java 中。

## 评测边界

- 隐藏种子集验证结构出现条件、边界、战利品引用和区块重载。
- 重复运行同一版本和种子必须保持既定不变量。
- 记录区块生成耗时与分配基线，明显退化必须失败。
- 必须通过资源对账、专服启动和 GameTest。
