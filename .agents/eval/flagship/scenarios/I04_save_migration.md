# I04 — Persistent schema migration

## Prompt

现有 Major 功能的持久化 schema 从 N 升级到 N+1。实现显式版本字段、向前迁移、
未知字段策略、损坏输入边界和可重复保存。不得通过删除旧数据或笼统 catch
异常“解决”升级问题。更新功能合同和 ADR 后再改实现。

## 评测边界

- 评测方提供未公开的 N-1 与 N-2 世界/实体/物品数据 fixture。
- 迁移后核心语义必须保留，再次加载和保存不得重复应用迁移。
- 不变量破坏应带上下文失败；可恢复的外部数据应被明确拒绝或隔离。
- 必须通过 Codec 往返、迁移 fixture、专服启动和行为回归。
